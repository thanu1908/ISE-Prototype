# 🧠 ISE — Interactive Skills Enhancer

> **"Practice safely. Learn independently. Grow confidently."**

ISE is a VR-based assistive learning platform designed for children with Autism Spectrum Disorder (ASD) and Intellectual Disabilities (ID). It allows children to safely practice everyday social, communication, decision-making, and safety skills inside controlled, repeatable virtual scenarios.

## 🎯 What Problem Does ISE Solve?

| Problem | ISE Solution |
|---------|-------------|
| Unpredictable real-world situations | Controlled virtual environments |
| Limited safe practice opportunities | Repeatable scenarios |
| One-size-fits-all learning | Adaptive difficulty (3 levels) |
| Punitive feedback systems | Supportive, never punitive |

---

## 🎮 Interactive Scenarios

| Scenario | Skills Practiced | Status |
|----------|-----------------|--------|
| 🏫 Classroom | Greeting, following instructions, asking for help | ✅ Fully Interactive |
| 🛒 Shopping | Selecting items, asking price, cashier interaction | ✅ Fully Interactive |
| 🚦 Road Crossing | Identifying signals, waiting safely, crossing | ✅ Fully Interactive |
| 🚌 Bus Stop | Waiting, identifying bus, asking for assistance | ✅ Fully Interactive |

## ✨ Key Features

- **4 Interactive Simulations** — Play through real-world scenarios
- **Supportive Feedback Engine** — Never punitive, always encouraging with hints
- **Adaptive Difficulty** — 3 levels: Guided → Supported → Independent
- **Skill Fingerprint** — Radar chart tracking 6 skill dimensions
- **Educator Dashboard** — Monitor learner progress and get recommendations
- **Parent/Caregiver View** — Simple progress tracking
- **Responsive Design** — Works on laptop, tablet, and mobile
- **Child-Accessible UI** — Large buttons, minimal text, clear icons

---

## 🏗️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Glassmorphism, gradients, animations, responsive design
- **JavaScript** — Interactive simulations, state management, radar chart (Canvas API)
- **No dependencies** — Single self-contained HTML file

## 🚀 How to Run

```bash

cd ISE-Prototype
open index.html
```

Or simply double-click `index.html` — no server needed!

## 📐 System Architecture

```

    → Adaptive Skill Engine → Progress Database → Educator/Caregiver Dashboard
```
